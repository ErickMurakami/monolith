# Monolith status

## Current milestone

Foundation and the first native application are implemented. Desktop Experience work has delivered the experimental Spotlight application launcher, calculator, window switcher and opt-in Dock.

- `src/windows.rs` owns the borderless Spotlight window lifecycle, keyboard navigation, focus dismissal and shortcut registration. Spotlight fades in over 120 ms on opening, after the first-open work, with the edit field focused at once. A launch-timeline check saw opacity rise 99, 231, 255.
- `src/overlay.rs` shares the native overlay styles, palette and DPI scaling between Spotlight and Dock.
- `src/hotkey.rs` owns `RegisterHotKey` registration and switches to Ctrl+Alt+Space when Windows reserves Win+Space.
- `src/search.rs` discovers Start menu desktop shortcuts and ranks local matches.
- `src/calculator.rs` evaluates bounded arithmetic expressions entered in Spotlight.
- `src/desktop.rs` discovers eligible windows and their display, detects fullscreen geometry and switches on explicit selection.
- `src/dock.rs` presents ordered, configurable Start menu pins and open windows on the primary display. The Dock handles live updates, minimisation, restoration and fullscreen suppression. Pins targeting an executable directly adopt that application's running group.
- `src/taskbar.rs` supports an opt-in Dock mode inside the existing primary Explorer taskbar band. A separate process restores native visibility when the Dock exits, and the Dock restores it if the companion exits first.
- `src/config.rs` validates TOML, preserves invalid files and supports a safe start.
- `src/top_bar.rs` reserves primary-monitor work area with a native AppBar and displays the local date, clock and battery in a borderless strip. Monochrome Segoe Fluent Icons buttons at its right end open Control Center and the Notification Centre. A blue dot marks unread notifications. Fullscreen windows and maximised foreground windows whose custom frames extend into the strip hide the bar and its hosted Island until the strip is clear.
- `src/preview.rs` owns the on-demand DWM thumbnail shown when hovering a running Dock tile.
- `src/icons.rs` extracts authentic Shell icons on a bounded worker and renders monochrome or original colours.
- `src/media.rs` subscribes to Windows media sessions and handles supported transport actions on a bounded WinRT worker.
- `src/artwork.rs` decodes current session artwork on demand with bounded Windows Imaging streams.
- `src/island.rs` presents real media metadata, controls and timeline progress in a borderless optional overlay. Expanded, it adds the album, elapsed and total time, supported shuffle and repeat, and click-to-seek. Expansion and collapse animate the height over 180 ms (ease-out) with a timer that exists only during the transition, and respect the Windows animation-effects setting. The smoke test observed eight intermediate heights from 34 to 104 px.
- `src/control_center.rs` adjusts the default audio output and internal display brightness (`src/brightness.rs`, WMI), displays available battery data and opens documented Windows Settings pages. `src/audio.rs` bounds updates and releases Core Audio subscriptions when the panel closes.
- `src/notifications.rs` presents new Windows toasts, read-only, in a non-activating banner below the Island when `notifications = true`.
- `src/workspaces.rs` reads native desktop order and the current desktop, read-only, and selects desktops by position. Mission Control names the current desktop and its position when there is more than one desktop or the desktop has a name. With `workspace_shortcuts = true`, `src/space_bridge.rs` maps Win+1-9 to those desktops and Win+Tab to Mission Control.
- `src/mission.rs` displays a native borderless window overview with live DWM thumbnails, the shared Dock inventory, paging, keyboard and mouse selection and a Windows Task View action.
- `src/files.rs` owns a native, on-demand Files window with a custom title surface, virtualised navigation, standard Windows folders and default app activation. `src/files_directory.rs` loads directories off the GUI thread and preserves history on failures.
- `src/quick_look.rs` opens a borderless text, image, PDF or metadata preview on Space in Files. `src/quick_content.rs` bounds reads and pixel counts and uses platform decoders.
- `src/file_changes.rs` performs same-directory rename and folder creation without overwriting an existing destination.
- `src/file_git.rs` provides opt-in branch, locally known upstream and file status through a bounded, read-only Git worker.
- `src/file_launch.rs` opens the terminal in the displayed directory and passes a selected project to the configured IDE.
- `src/file_clipboard.rs` and `src/file_transfer.rs` implement on-demand native Files copy, cut and paste with Shell clipboard interchange, collision-safe naming and cancellation requests.
- `src/file_recycle.rs` recycles the selection on Delete or from the context menu through the Shell transfer source. It never falls back to permanent deletion.
- `benchmarks/measure.ps1` samples Windows and Monolith memory, CPU and I/O.
- The benchmark also records the busiest GPU engine from WDDM counters when available.

- `docs/dock.png` shows the running replacement Dock centred in the native taskbar band.
- `docs/top-bar.png` is a cropped live capture of the Top Bar status area.
- `docs/island.png` shows the Island controlling a real Helium media session carrying local test audio.
- `docs/control-center.png` shows the live borderless panel and the Windows settings actions.
- `docs/mission.png` shows a cropped capture of two real DWM thumbnails for verification windows.

- `docs/quick-look.png` shows the native preview rendering a verification PNG.
- `docs/files-git.png` shows the branch and item states of a real verification repository.

The Dock groups running windows by packaged application ID or verified process image, opens a native window chooser and previews the active or first visible window in a group. It can follow the active display, retract to a pointer reveal strip and show native Shell icons for pins and running groups. The Island shows title, artist, artwork, available transport controls and progress from the Windows timeline. Simultaneous per-display Docks, additional Top Bar modules, media and Android integrations for Control Center, workspaces, Files previews and operations, indexing, tuning, settings UI, Android integration and installers are pending.

## Git and recovery

The binary needs no elevation and makes no persistent changes to Windows. Dismiss standalone Spotlight or use **Exit** on the Dock to stop the process and release native hooks. Pass `--safe-mode` to bypass configuration and start Spotlight alone. Rename the configuration file to recover defaults. Portable removal consists of closing the process and removing the executable, with optional removal of the local configuration directory.

## Shortcut compatibility

With `win_space_override = true`, Win+Space opens Spotlight through `src/space_bridge.rs` on build 26300.9974, where direct registration returns error 1409. The earlier bridge lost the first character because its hook ran on the busy GUI thread and keys typed before activation reached the previous window. The new hook runs on a dedicated thread and replays buffered keys once Spotlight has focus. `tests/desktop-smoke.ps1 -Hotkey -WinSpace` passed in normal, maximised, minimised and fullscreen states, typing 15 ms after the chord. The `-Combined` variant with Dock, Top Bar and Island passed three of three runs, including a clean restart and shortcut recovery after forced termination. The Ctrl+Alt+Space test still passes. The bridge stays opt-in until a physical keyboard, dead-key layouts and an elevated foreground window have been tested.
The bridge now also serves the opt-in `workspace_shortcuts` setting: Win+1-9 select native desktops in Explorer's order, and Win+Tab toggles Mission Control through a registered Ctrl+Alt+F24 fallback. Unit tests cover chord selection, replacement while the logo key is held, disabled and modified chords, desktop-order parsing and step calculation. A live read of the desktop order succeeded. Not yet validated live: `tests/workspace-navigation-smoke.ps1 -Shortcuts` and a repeat of `tests/desktop-smoke.ps1 -Hotkey -WinSpace -Combined` after this refactor. Both send global keyboard input and need a hands-off desktop. Win+Shift+number remains unimplemented: the public `MoveWindowToDesktop` refuses windows owned by other processes.
